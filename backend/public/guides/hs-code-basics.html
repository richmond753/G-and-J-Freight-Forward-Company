HS code basics

HS codes tell Customs what your goods are. The right code drives duty rates, permits, and whether clearance is smooth or stuck.

What is an HS code?

The Harmonized System is an international product naming system. Codes usually appear as 6 digits globally; countries add extra digits for national tariffs (Ghana uses extended digits for local duty schedules).

Why it matters

  • Determines import duty and VAT treatment
  • Flags goods that need permits or standards checks
  • Must match the commercial invoice description

Common mistakes

  • Copying a supplier’s code without checking local tariff notes
  • Using a vague description (“spare parts”) that does not match the code
  • Mixing multiple products under one incorrect heading

Practical tip

Keep a clear product description, material composition, and intended use ready. When in doubt, ask your forwarder or a licensed agent before the vessel arrives — fixing codes after arrival costs time.
